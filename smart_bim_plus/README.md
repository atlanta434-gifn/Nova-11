# Smart BIM+ — AI-Powered Building Design Automation

## English
Smart BIM+ is an advanced Windows desktop application that integrates drone data, artificial intelligence, and BIM (Building Information Modeling) to automate the design of buildings across 20 different technical systems.

### Features
- **DSBA Algorithm**: Drone-to-Smart-BIM Algorithm for photogrammetry and automatic building envelope generation.
- **AI Optimization**: ONNX Runtime integration for room layout optimization and standard-based scoring.
- **Modular Architecture**: 20 distinct modules covering Plans, Electricity, HVAC, Plumbing, AI Simulation, and more.
- **Export Capabilities**: Generate DXF drawings, IFC4 BIM models, and PDF reports.

### Setup
1. Create a virtual environment: `python -m venv venv`
2. Activate it: `venv\Scripts\activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the app: `python core/app.py`

## العربية
برنامج Smart BIM+ هو تطبيق مكتبي متقدم لنظام التشغيل Windows يدمج بين بيانات الطائرات المسيرة (الدرون)، الذكاء الاصطناعي، ونمذجة معلومات البناء (BIM) لأتمتة تصميم المباني عبر 20 نظاماً هندسياً مختلفاً.

### الميزات
- **خوارزمية DSBA**: خوارزمية فريدة تحول بيانات الدرون إلى نماذج BIM ذكية تلقائياً.
- **تحسين عبر الذكاء الاصطناعي**: دمج محرك ONNX لتحسين تخطيط الغرف وتقييم التصميم وفق المعايير.
- **بنية معيارية**: 20 وحدة تغطي المخططات المعمارية، الكهرباء، التكييف، السباكة، المحاكاة، وغيرها.
- **قدرات التصدير**: توليد رسومات DXF، نماذج IFC4، وتقارير PDF.

### التشغيل
1. إنشاء بيئة افتراضية: `python -m venv venv`
2. تفعيل البيئة: `venv\Scripts\activate`
3. تثبيت المتطلبات: `pip install -r requirements.txt`
4. تشغيل التطبيق: `python core/app.py`
