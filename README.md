# Smart Home AI Blueprint Platform

An AI-powered platform for generating and visualizing smart home blueprints.

## Tech Stack
- **Backend:** FastAPI, Python 3.9+
- **Frontend:** React, Vite, Tailwind CSS, Three.js

## Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Features
- AI-driven blueprint generation
- 3D visualization with layers
- Layer-based editing and sync
